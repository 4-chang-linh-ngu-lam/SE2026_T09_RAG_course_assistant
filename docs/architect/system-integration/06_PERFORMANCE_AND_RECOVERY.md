# Performance và recovery
358 concurrent users; Locust hoặc k6. Workload giả định: classroom/feed 35%, Document 20%, practice/assignment 25%, AI Tutor 15%, notification 5%; xác định think time, duration, ramp, dataset, request mix và real/mock AI riêng. Không đồng nhất concurrent users với inference concurrency. Mục tiêu sơ bộ p95 CRUD <=500ms, auth <=200ms, analytics <=2s, AI timeout 60s, HTTP 5xx <1%, không mất acknowledged submissions/grades/data; fault isolation. Đối chiếu QA gốc trước acceptance, chưa benchmark.
Backup daily và trước migration quan trọng: từng PostgreSQL DB, Document file+metadata nhất quán, AI index backup/rebuild từ nguồn hợp lệ. Restore test trên Testing, kiểm tra checksum/data consistency. Images theo SHA; rollback image chỉ khi schema tương thích; migration rollback/forward-fix plan. RPO/RTO/retention/offsite encryption cần chốt; single VPS/DB SPOF. Không coi backup thành công nếu chưa restore.
