# Gateway và security
Nginx public HTTPS, request ID, size/rate limits. Allowlist route theo method/path, deny mặc định internal/unknown; không expose DB/service ports. / -> Next.js; /api/v1/auth, users, admin, reports, posts, comments -> Core; documents -> Document; questions, assessments, assignments, attempts, grades, practice-sessions, ai-jobs -> Learning; notifications, notification-preferences -> Notification; ai -> AI. Classroom nested routes documents -> Document; questions/assessments/assignments/practice-sessions/analytics/recommendations/question-generation-jobs -> Learning; posts/members và Admin classroom lifecycle -> Core; deny join/invite/self-leave/owner-transfer draft aliases. Đây là routing inventory đề xuất, kiểm tra exact paths, precedence, methods, prefix rewriting, frontend compatibility trước config. Chặn /internal/* và mọi alias/encoded bypass.
User JWT access/refresh; shared package `lumi-service-auth` cho Service JWT và config adapter riêng từng service; issuer/audience/caller-specific scope/expiry/source identity. Core current authorization + local resource checks. Không tin user_id frontend. Package đã có signer/verifier; key issuance/distribution/rotation trên môi trường và consumer rollout vẫn pending. TLS public và untrusted internal links; secrets không commit, redact logs. Fail closed khi không xác minh quyền. CORS/CSRF/cookie policy phải đối chiếu auth transport hiện tại.
