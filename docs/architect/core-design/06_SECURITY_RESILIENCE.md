# Security và resilience — CORE-T04/T07

Mỗi service có signing key riêng; trust policy ràng buộc kid/issuer/sub/key/audience và caller-specific scopes. Token lifetime tối đa 300 giây, clock skew tối đa 30 giây. Key provisioning/distribution/rotation runbook và consumer rollout vẫn cần cấu hình. Access
Outbox cùng transaction, worker lease/fencing, HTTP ngoài transaction, backoff+jitter, bounded retry/concurrency, circuit breaker theo DOC-T05; dedup phía nhận.
