# Security và resilience — CORE-T04/T07
JWT access/refresh; RS256/JWKS hoặc cơ chế tương thích an toàn; access 15 phút, refresh 7 ngày là đề xuất. Argon2id hoặc hash an toàn hiện có. Hash refresh, rotation, reuse detection, logout revoke session. Kiểm tra trạng thái user và membership hiện hành; role token không là nguồn duy nhất. Service JWT riêng từng service, key management pending; rate limit login/register/refresh/join; audit admin/quyền, không log secrets. Internal API không public.
Outbox cùng transaction, worker lease/fencing, HTTP ngoài transaction, backoff+jitter, bounded retry/concurrency, circuit breaker theo DOC-T05; dedup phía nhận. AI/Document/Learning/Notification offline không chặn nghiệp vụ Core độc lập. PostgreSQL offline không báo thành công giả. Fail closed khi không xác minh quyền. TLS trên mạng không tin cậy.
